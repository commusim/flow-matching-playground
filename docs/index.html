第一章

基础Flow Matching理论

先定义路径，再让神经网络学习每个时间与位置上的瞬时速度。

1. 样本与噪声

数据样本记为 x_data，起点噪声记为 x_noise。二维实验中的一个点是一条完整样本；图像实验中的一个点是一整张高维图像。

2. 条件路径

xₜ = (1 − t)x_noise + t x_data

t=0是噪声，t=1是数据。

3. 速度回归

uₜ = x_data − x_noise

模型学习 vθ(xₜ,t,c) ≈ uₜ，其中c是可选条件。

4. ODE采样

dx / dt = vθ(x,t,c)

从高斯噪声开始，重复查询速度并进行数值积分。

关键区别： 轨迹是一个样本随时间经过的位置；速度场是在给定时间下，空间中每个位置对应的移动方向。条件会改变整套随时间变化的速度场。
第二章

二维数据：无条件与有条件Flow

拖动时间，直接观察点云、目标分布和速度箭头如何同时变化。

目标分布 当前粒子 当前速度

无条件速度场

模型只根据当前位置和时间预测速度。若数据分布具有多个模式，模型必须从噪声中自行决定最终模式。

有条件速度场

同一位置与时间，在条件0和条件1下可以得到不同速度： vθ(x,t,c₀) ≠ vθ(x,t,c₁)。

如何阅读速度场

箭头方向表示局部移动方向，长度表示速度大小。应同时观察粒子是否沿箭头进入目标分布，而不是只看最终点云。

第三章

MNIST初探：从像素CNN到条件U-Net

先理解理论差异，再通过同一噪声、同一Label和同一时间查看实际生成过程。

模型 生成空间 条件方式 全局结构 当前表现
入口加法条件CNN 28×28像素 入口加入Label 弱，局部感受野 大量错误与unknown
AdaGN条件CNN 28×28像素 每层scale/shift 仍为平坦CNN 条件增强但整体结构不足
VAE latent Flow 8×7×7 latent latent条件CNN 压缩后更平滑 明显优于平坦像素CNN
条件U-Net Flow 28×28像素 AdaGN + CFG 7×7 Bottleneck + Skip 类别控制最稳定

为什么VAE会改善？

VAE把784维像素压缩到392维latent，并用Decoder提供数字形状先验。生成器不再逐像素处理高频噪声，更容易形成闭环和笔画。

为什么VAE不是万能的？

压缩空间不会自动增强条件控制。若latent速度网络缺乏多尺度结构、Guidance或足够容量，仍会出现类别混淆。

为什么U-Net更强？

7×7 Bottleneck负责数字全局拓扑，Skip Connection恢复局部笔画，逐层AdaGN持续注入Label，CFG放大条件方向。

目标：0 分类器预测：unknown 最大置信度：0%

第五章

如何理解结构差异

平坦CNN

主要学习局部像素修正，速度不一定朝目标语义簇移动。

VAE latent Flow

压缩表示减少高频像素搜索，并通过Decoder提供图像先验，因此比平坦像素CNN更容易形成数字。

条件U-Net

多尺度全局规划、Skip Connection、逐层条件调制和CFG共同产生方向更正确的语义速度场。

评价原则

同时观察原图、真实语义簇、分类置信度、速度方向与目标距离，不能只凭一张降维图判断模型是否正确。
