二维 Flow Matching 交互教程

拖动时间 t，观察同一个初始噪声如何在条件速度场中移动。二维中的一个粒子代表一个完整样本；在图像模型中，它对应一张图像的高维 latent。

你正在观察什么？

目标分布：训练数据所在的形状。
当前粒子：从高斯噪声出发、经过速度场运输到当前时刻的位置。
箭头：模型在位置 x、时间 t 和条件 c 下预测的瞬时速度。
条件：不是生成结束后贴上的标签，而是每一步都改变速度场：vθ(x,t,c)。

Flow Matching训练模型拟合 u = x_data - x_noise；推理时求解 dx/dt = vθ(x,t,c)。本页面用一个简化的解析速度场模拟这一过程，帮助理解几何关系。
